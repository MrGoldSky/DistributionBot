# Telegram-бот для записи на сдачу лабораторных работ

Этот проект представляет собой простого Telegram-бота, написанного на Python. Бот позволяет:

- Регистрировать пользователей.
- Вести запись на ближайшую сдачу лабораторных работ.
- Просматривать текущий список записей.
- Удалять записи (как свою, так и все записи для администратора).

## Используемые библиотеки

- **Telebot** - для работы с Telegram API.  
  [Telebot GitHub](https://github.com/eternnoir/pyTelegramBotAPI)
- **SQLite** - для хранения данных о регистрации и записях.
- **datetime** - для работы с датой и временем.

## Конфигурация

Параметры для работы бота задаются в файле `config.py`, который должен содержать:
- `BOT_TOKEN` - токен вашего бота.
- `BASE_PATH` - путь к файлу базы данных SQLite.
- `LAST_RUN_FILE` - путь к файлу для хранения времени последнего запуска.
- `OWNER` - идентификатор владельца бота (для доступа к административным функциям).
